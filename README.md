# CampsiteCommander2
Description
An app that store camping gear and food supplies and allow users to categorize them.

Features
Welcome screen with a title and a logo
Mainscreen that display buttons for "Add Gear" and also display the total items packed.
Detailed view screen that display button for full list of gear with details and a back to base button
Comments and error handling per rubric

How to Run
Clone:https://github.com/mohlalakgopotso442-glitch/CampsiteCommander2
Open in Android Studio
Click Run ▶️
